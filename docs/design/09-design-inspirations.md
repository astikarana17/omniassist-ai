# OmniAssist AI — Design Inspirations & Borrowed Patterns

> v1.0 · What we take from the best, and how we apply it. Inspiration, not imitation.

## 1. Linear — *Speed & density*
**What's great:** keyboard-first, command palette, instant transitions, dense but calm lists, restrained color, perfect dark mode.
**We borrow:**
- cmd-K command palette as the primary power-user surface.
- Keyboard shortcuts for every core action (assign, resolve, navigate).
- List density + subtle row hover actions in Inbox/Tickets.
- Near-instant view transitions; no loading spinners on navigation.
- Active-nav pill that slides between items.

## 2. Stripe — *Trust & precision*
**What's great:** immaculate typography, gentle shadows, clear data tables, world-class docs, calm light mode, financial-grade polish.
**We borrow:**
- Refined table design (alignment, tabular numbers, quiet borders).
- Subtle elevation in light mode (shadows over glow).
- Trust signals in settings/security pages.
- Documentation-grade clarity for KB and API key screens.

## 3. OpenAI — *Spacious confidence + AI UX*
**What's great:** generous whitespace, big confident type, restrained palette, conversational AI surfaces, streaming responses.
**We borrow:**
- Spacious marketing + auth layouts.
- Chat/streaming patterns (token-by-token, stop button, regenerate).
- Minimal chrome around AI conversations.

## 4. Cursor — *AI woven into the workflow*
**What's great:** AI as an ambient copilot inside the work surface, inline suggestions, diff-style accept/reject, context awareness.
**We borrow:**
- Agent **Copilot** panel beside Inbox/Tickets (suggest replies, summarize, draft).
- Accept / edit / regenerate controls on AI drafts.
- Context-aware suggestions ("Based on this thread, suggest a reply").

## 5. Vercel — *Premium dark aesthetic + dashboards*
**What's great:** black/near-black canvas, geometric precision, beautiful deploy dashboards, gradient accents, Geist type.
**We borrow:**
- Dark-first canvas (#08080A), Geist typography.
- Gradient accents used sparingly on CTAs and hero.
- Clean project/dashboard card grids.
- Status indicators (live dots, build-like progress for KB indexing).

## 6. Notion — *Flexible, friendly structure*
**What's great:** approachable IA, blocks, side peek panels, gentle onboarding, content-first.
**We borrow:**
- Side **peek drawers** for detail (ticket/lead) without losing list context.
- Friendly empty states + inline onboarding nudges.
- Flexible saved views / filters.

## 7. Lovable — *Delight & momentum*
**What's great:** playful-yet-premium motion, instant feedback, "it feels alive" micro-interactions, fast generate loops.
**We borrow:**
- Micro-interactions that reward actions (subtle success glow, count-ups).
- Momentum in flows — minimal steps, instant results.
- Tasteful motion that signals capability without being childish.

## 8. Synthesis — OmniAssist's own voice

| Dimension | Our position |
|-----------|--------------|
| Canvas | Dark-first like Vercel, light as polished as Stripe |
| Speed | Linear-fast, keyboard-first |
| AI surface | Cursor-style copilot + OpenAI streaming |
| Structure | Notion-flexible peek panels |
| Motion | Lovable-delightful, Linear-restrained |
| Trust | Stripe-grade detail for enterprise buyers |

**The differentiator:** OmniAssist makes **AI visible and trustworthy** — every answer shows sources + confidence, every automation has a human escape hatch. That transparency, wrapped in this level of polish, is the brand.

## 9. Anti-patterns (what we refuse to do)
- No rainbow gradients on everything (gradient = accent only).
- No spinner-on-everything; skeletons instead.
- No glassmorphism on dense text/tables.
- No mystery-meat icons without labels.
- No AI that hides its sources or has no human handoff.
- No motion for motion's sake.
